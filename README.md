# UNO · Tour do app (Igreja Kairos)

Tutorial interativo do aplicativo UNO, com opção de narração em português (voz Francisca).

## Como publicar o link (um passo)

O site já está montado na branch `publish`. Para gerar o link público:

1. Abra [Settings → Pages](https://github.com/tiagolyssenko-commits/uno-tour-kairos/settings/pages)
2. Em **Build and deployment**, escolha **Deploy from a branch**
3. Branch: **publish**, pasta: **/ (root)**
4. Clique em **Save**

Em cerca de um minuto o tour abre em:

**https://tiagolyssenko-commits.github.io/uno-tour-kairos/**

No início você escolhe **Com narração** ou **Sem narração**. Dá para ligar ou desligar o áudio a qualquer momento no botão de som no topo.
